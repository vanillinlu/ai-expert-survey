如何安全發送給專家填寫（無警訊）？

為什麼直接傳檔案會有安全性警訊？
若直接用 LINE/Email 傳送未託管的 HTML 檔案，手機或 Chrome 瀏覽器會視為本機未知腳本，跳出紅黃色「可能含有危險」警訊，且專家填寫的資料只會存放在他自己的手機，您後端無法收到。

推薦 2 種「安全、免費、無警訊（HTTPS 綠色鎖頭）」發送方案：

最快 1 分鐘 方案 A：使用 GitHub Pages 免費發布（推薦）
  1. 登入 GitHub 建立一個公開 Repository（例如叫 ai-survey）。
  2. 將本檔案命名為 index.html 上傳。
  3. 到 Settings ➔ Pages ➔ Branch 選擇 main 儲存。
  4. 您將獲得專屬的官方安全網址（如 https://yourname.github.io/ai-survey/），專家點開百分之百安全無任何警報。
拖曳即發布 方案 B：使用 Vercel / Netlify 拖曳部署
  1. 將本檔案命名為 index.html 放入一個資料夾。
  2. 直接拖入 Vercel 或 Netlify Drop 網站。
  3. 立即獲得全球 CDN 加速的正式 HTTPS 專屬短網址，手機與電腦秒開無警告。
